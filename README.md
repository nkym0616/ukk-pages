# ukk-pages


UKKの部員向けタスク管理アプリの、GitHub Pages配信用のビルド済みフロントエンドです。

公開URL: https://nkym0616.github.io/ukk-pages/

Googleログイン、部員の承認、役職・コンテスト・タスクの保存は別の本番バックエンドが処理します。このリポジトリにGoogleクライアントシークレット、データベース接続情報、部員データは含まれていません。部員データの閲覧・操作にはログインとアプリ内の権限が必要です。

Pagesの公開元は `main` ブランチのルート `/` です。ビルド済み画面のみを配置し、`.nojekyll` によりそのまま配信します。
